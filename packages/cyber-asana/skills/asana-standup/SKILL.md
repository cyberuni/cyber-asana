# Asana Standup (moved)

This skill moved into `asana-scrum`, which computes the standup in the CLI instead of asking you to
sort task lists. This stub stays for one minor release, then it is deleted.

Load the `asana-scrum` skill from the cyber-asana plugin and follow its **Standup** route with the
user's request as input. Do not run the old `task list --completed-since` steps.
