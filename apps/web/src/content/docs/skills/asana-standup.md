The `asana-standup` skill moved into [`asana-scrum`](/cyber-asana/skills/asana-scrum/), which computes
your standup in the CLI (`cyber-asana report standup`) instead of asking the model to sort task
lists. The skill stays as a stub that routes to `asana-scrum` for one minor release, then it is
deleted. Use `asana-scrum` or `/cyber-asana:standup` instead.
