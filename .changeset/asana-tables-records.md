Support Asana Tables and Records: `table` and `record` CLI commands and `asana_table_*` and `asana_record_*` MCP tools, a `tables` and `records` API on the runtime context and the package exports, and table and record parents in `membership` commands. Tables need an Advanced, Enterprise, or Enterprise+ plan, and record search needs a paid plan.
